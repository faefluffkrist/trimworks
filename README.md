# Trimworks

A Fabric mod for Minecraft 26.2 that adds configurable armor trim effects, pattern abilities, material bonuses, and advancements. Requires Fabric API; Mod Menu and Naturally Trimmed are optional.

Thank you for using Trimworks. Created by **faefluffkrist**, with thanks to ParroteX2 for the original MIT-licensed TrimEffects project.
