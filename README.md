# Trimworks

**Trimworks** is a Fabric mod for Minecraft 26.2 that makes armor trims matter, granting configurable status effects and special built-in abilities, while trim materials provide smaller utility bonuses of their own.

Created by **faefluffkrist**.

Thank you for using my mod!! Trimworks began as an extension of ParroteX2's MIT-licensed TrimEffects project before growing into a standalone mod; thanks to ParroteX2 for the original inspiration.

## Requirements

- Minecraft 26.2
- Fabric Loader 0.19.3 or newer
- Fabric API 0.155.2+26.2 or newer
- Java 25
- Mod Menu is optional. It provides convenient access to Trimworks' configuration screens but is not required for gameplay or dedicated servers.

Trimworks is standalone: the original `mr_trimeffects` mod/datapack is **not required** and should not be installed alongside Trimworks.
